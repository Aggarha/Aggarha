# Aggarha Foundation

Production-ready application foundation for Aggarha.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- ESLint + Prettier
- PWA support
- Docker build/runtime

## Environment
Copy `.env.local.example` to `.env.local` for local development.

## Commands
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run typecheck`
- `npm run format:check`
